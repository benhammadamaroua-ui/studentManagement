
# Student Management System

## Description
This is a simple Python project for managing students.
It is created as part of the Project Management practical session.

## Features
- Display a welcome message.
- Introduce the student management system.

## Project Structure
- `src/main.py`: Contains the main Python code.
- `tests/test_main.py`: Contains the project tests.
- `README.md`: Contains the project documentation.

## Requirements
- Python 3

## How to Run
Open a terminal in the project root directory and run:

```bash
python3 src/main.py
```
